## Установка APK

```
adb install -r K-Matule.apk
```

или скопировать файл на устройство и открыть (нужно разрешить установку из неизвестных источников).

## Проверка подписи

```
apksigner verify --print-certs K-Matule.apk
```

Скриншоты сделаны в разрешении 1080×2340 и соответствуют текущей вёрстке приложения.
